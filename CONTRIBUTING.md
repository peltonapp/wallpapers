# Contributing

Thanks for wanting to add to the Pelton wallpaper set. This repo is art plus a
small script, so the bar is mostly about file layout and consistency.

## Folder layout

Every wallpaper lives in its own variant folder:

```
wallpapers/<platform>/<set>/<number>/<variant>/
```

- **platform** is `desktop` or `mobile`
- **set** is the design family, for example `night` or `plate`
- **number** separates designs inside a set, starting at `1`
- **variant** describes what is different, for example `default`,
  `no-marker`, `no-marker-no-compass`

A real example:

```
wallpapers/desktop/night/1/default/
  night-1-default-3840x2160.jpg
  night-1-default-3840x2160.png
  night-1-default.svg
```

## File rules

- Ship all three formats in each variant folder: **JPEG**, **PNG** and **SVG**.
  The JPEG is what the gallery shows, the PNG and SVG are download options.
- Name the raster files `<set>-<number>-<variant>-<width>x<height>`. The gallery
  reads the resolution straight out of that suffix, and falls back to the PNG
  header if it is missing.
- Name the SVG `<set>-<number>-<variant>` with no resolution, since it scales.
- Desktop exports are 3840x2160. Match the existing files unless you have a
  reason not to.
- Keep the SVG editable rather than a single embedded bitmap. That is the whole
  point of shipping it.

## The gallery

Do not hand-edit the gallery section of `README.md`. Everything between the
`<!-- gallery:start -->` and `<!-- gallery:end -->` markers is generated by
[`scripts/generate_gallery.py`](./scripts/generate_gallery.py) and the Gallery
workflow rewrites it on every push to `main`. The prose around it is yours to
edit freely.

To preview your changes locally:

```sh
python3 scripts/generate_gallery.py
```

It needs nothing but Python 3 and a git checkout with history, since authors are
read from git. A new platform folder shows up automatically, and an empty one
renders as *Nothing here yet.*

## Attribution

The author shown under each wallpaper comes from the newest commit touching its
files. If you are committing someone else's art, credit them with a trailer and
they will be listed first:

```
Co-authored-by: Their Name <their@email>
```
